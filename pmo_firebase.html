🔑 Настройка Firebase

Подключите облачную базу для совместной работы

Пошаговая настройка:

  1. Откройте Firebase Console и войдите под Google-аккаунтом
  2. Нажмите «Добавить проект», задайте имя (например, pmo-orders)
  3. В меню слева выберите Build → Firestore Database → Создать базу
    Выберите режим тестирования (test mode), регион — Европа
  4. На главной странице проекта нажмите «</>» (Web) → задайте имя приложения
  5. Скопируйте блок const firebaseConfig = {'{' ... '}'}
  6. Откройте этот HTML-файл в текстовом редакторе, найдите FIREBASE_CONFIG и вставьте значения
  7. В Firestore Console → Rules вставьте правила (см. ниже)
  8. Откройте файл заново — индикатор покажет ☁ Облако

Правила Firestore:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /pmo_data/{document=**} {
      allow read, write: if true;  // пока без авторизации
    }
  }
}

⚠ Для продакшена замените if true на проверку авторизации (Firebase Auth). Пока if true — любой с ссылкой может редактировать.
